# Appyapp — site

Site vitrine d'Appyapp (Sunory, AquaShot), publié avec GitHub Pages :
https://michi75-coder.github.io/appyapp/

- Une seule page statique, `index.html` : HTML, CSS et JS en ligne, icônes des apps en data URI.
- Français par défaut, anglais selon la langue du navigateur ou le bouton EN.
- Publication : Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.
